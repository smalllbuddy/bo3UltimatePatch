# BO3 Ultimate Patch

One download that puts three ways to play **Call of Duty: Black Ops III** on PC behind a single
launcher.

| Mode | Starts |
|---|---|
| Solo (offline) | `BO3.Offline.exe`: SJ Offline |
| LAN co-op | `BO3.Lan.exe`: BOIII |
| Steam co-op | `BO3.Steam.exe` |

## Install

1. You need your own copy of Black Ops III on Steam.
2. Download the zip from [Releases](https://github.com/smalllbuddy/bo3UltimatePatch/releases) and
   extract everything into your main Black Ops III folder. Replace files when asked.
3. Run `BO3.Launcher.exe` and pick a mode.
